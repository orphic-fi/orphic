# Fonts

Self-hosted, latin subsets, woff2 only.

- `commit-mono/`: Commit Mono by Eigil Nikolajsen (commitmono.com), weights 400, 500, 700. Licence in `commit-mono/LICENSE` (SIL Open Font License 1.1, as shipped with the font).
- `inter/`: Inter by Rasmus Andersson (rsms.me/inter), variable weight axis. Licence in `inter/LICENSE` (SIL Open Font License 1.1).

Files were taken from the fontsource packages `@fontsource/commit-mono@5.3.0` and `@fontsource-variable/inter@5.3.0`, which repackage the upstream releases unchanged apart from subsetting.
